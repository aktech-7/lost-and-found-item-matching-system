# Intelligent Lost and Found Item Matching System

## Introduction

The Intelligent Lost and Found Item Matching System is a Python-based application used to automatically find possible matches between lost and found items.

## Features

- Register lost and found items
- Store item name, colour and location
- Compare item descriptions
- Calculate matching score
- Display possible matches

## Technologies Used

- Python
- pandas
- scikit-learn
- NumPy
- Tkinter
- SQLite3

## Installation

1. Download the project.
2. Open the project folder.
3. Run the Python program.

## Usage

1. Enter the lost item details.
2. Enter the found item details.
3. Compare the item descriptions.
4. View the possible matches.
